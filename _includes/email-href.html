{%- comment -%} Emit a `mailto:` href with every letter and punctuation mark replaced by its numeric HTML entity, scheme included, so the page carries no crawlable address. The browser decodes the entities while parsing the attribute, so the link works normally. This stops a scraper that regex-matches raw HTML; it does not stop one that parses the document first, and it is not meant to. Digits and uppercase letters pass through unchanged, which is safe: an inserted entity contains only `&`, `#`, digits and `;`, so no replacement can corrupt the output of an earlier one.
