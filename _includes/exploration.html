{%- comment -%} The exploration map in the footer. Without JavaScript it is a plain
listing the sections and a link to /everything/. exploration.js moves the same contents into a dialog and shows "Take me somewhere new", which goes to a random section not yet visited in this browser (English and Italian pages share a `data-visit` ref). The visits are kept in localStorage only for that choice; the map does not show them. If storage is unavailable, the button picks any other section. {%- endcomment -%} {% assign explore = site.data.ui.exploration %}
