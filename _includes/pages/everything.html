{%- comment -%} The dense index, on its own page rather than inlined into the other pages. Ordering: Liquid has no way to sort one list built out of differently shaped ones, so each entry contributes a `"||"` string, the strings are sorted as text (which is why the dates are zero-padded and written biggest unit first), and the loop dereferences each one back to its source. Nothing is copied into a second data file; `_data/research.yml` and `_data/projects.yml` stay the only place these entries exist. The MSc thesis is the `thesis` block of its role in `_data/research.yml`. The filter is radio inputs plus `:has()`, no JavaScript: "all" is checked in the HTML, so the page's default and its no-script state are the same complete list. The per-filter counts are all rendered at build time and CSS shows the one that matches, so the number is right without a script to recompute it. Papers, projects and the thesis are listed. The thesis is labelled as a thesis but filters with the papers (its row's `data-kind` is `paper`), so there is no filter for a kind with a single entry, and none for kinds that do not exist yet. Paper bylines set his name in bold, as on /research/. A project with a `paper` links to that paper's entry on /research/, and its `where` fills the Where cell. {%- endcomment -%} {%- assign papers = site.data.research.papers -%} {%- assign roles = site.data.research.roles -%} {%- assign projects = site.data.projects.items | where: "featured", true -%} {%- assign kinds = site.data.ui.everything.kinds -%} {%- assign research_page = site.pages | where: "lang", page.lang | where: "ref", "research" | first -%} {%- capture _me %}{{ site.data.profile.name }}{% endcapture -%} {%- assign rows = "" -%} {%- for p in papers -%} {%- assign k = p.date | default: "0000-00-00" -%} {%- assign rows = rows | append: k | append: "|paper|" | append: forloop.index0 | append: "," -%} {%- endfor -%} {%- assign n_thesis = 0 -%} {%- for r in roles -%} {%- if r.thesis -%} {%- assign k = r.thesis.date | default: "0000-00" | append: "-00" -%} {%- assign rows = rows | append: k | append: "|thesis|" | append: forloop.index0 | append: "," -%} {%- assign n_thesis = n_thesis | plus: 1 -%} {%- endif -%} {%- endfor -%} {%- for p in projects -%} {%- assign k = p.date | default: "0000-00" | append: "-00" -%} {%- assign rows = rows | append: k | append: "|project|" | append: forloop.index0 | append: "," -%} {%- endfor -%} {%- assign rows = rows | split: "," | sort | reverse -%} {%- assign n_all = rows | size -%} {%- assign n_paper = papers | size | plus: n_thesis -%} {%- assign n_project = projects | size -%} {% include page-head.html title=site.data.ui.sections.everything %}
